# RuNNer 与 MACE-POLAR 气体主动学习工作流

用户目标：在同一个仓库搭建可运行的委员会采样、VASP 单点标注、数据汇总及训练入口，同时接入 JCP RuNNer 2.0/runnerase，便于后续使用同一数据做比较。

实现采用 Python + ASE；共同数据单位为 eV、Å、eV/Å，时间统计统一 µs/atom/step。模型后端独立加载：MACE/PolarMACE 使用原生计算器，RuNNer 使用 runnerase。跨参考方法的模型不能默认混作经校准的委员会。

每轮数据写入新目录；已有结果不得覆盖。采样输出包含模型来源、原子力分歧、轨迹与候选，阈值显式标记为未校准。VASP 使用独立任务目录与 Slurm，单点任务强制 NSW=0，保留电子收敛检查、元素排序映射与结构一致性检查。DFT 方法尚未确定时可生成任务草案和检查环境；计算需要完整 reference 配置。数据划分按采样来源分组，避免相邻 MD 帧同时进入训练与验证。

训练入口为多个不同种子成员生成独立任务。MACE/PolarMACE 支持官方 CLI；RuNNer 保留其原生 input.nn/训练路径与 runnerase 数据转换。4G 训练所需原子电荷须具有明确分区定义和参考来源，不能把未提供的电荷自动填为训练标签。

验收：常规测试覆盖拒绝覆盖、分歧定义、去重、VASP 收敛拒绝、单位和数据划分；在 Slurm 计算节点跑真实模型采样/基准及 RuNNer 安装测试。模拟标签仅验证程序路径，不能称为 DFT 标签。之前旋转协变未通过的模型结果须保留限制说明。源代码、配置、文档和小型验证证据推送 GitHub，模型权重、环境和 POTCAR 不提交。
