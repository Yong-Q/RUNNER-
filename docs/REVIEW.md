# 审查记录

独立代码审查发现的六项重要问题均已修正：

1. 未分组的输入不再逐帧分配独立组，默认同一输入文件为同一来源。
2. 跨来源组的完全重复几何会阻止训练/验证划分。
3. 训练标签检查有限标量能量、N×3 有限力和 free_energy 约定。
4. VASP 参考参数不能绕过当前中性、单重态、无外场的输入范围。
5. 训练和 VASP 任务有独占执行记录；失败后使用新尝试目录，避免重复提交覆盖。
6. 收集标签时核对原结构的几何与电子态摘要；准备阶段还记录 VASP 输入文件摘要。

18 项单元测试通过。实际模型测试经原生 Slurm 运行；日志摘要及已知科学限制见 evidence/verification.json。新的 framework 不改变此前 MACE-POLAR M/L 旋转协变偏差的结论。
