# 当前流程试验的参考方法

2026-10-22 的首轮小样本真实标注使用 VASP PBE-D3(BJ)/PAW：ENCUT=520 eV、Γ 点、EDIFF=1e-7 eV、ISMEAR=0、SIGMA=0.05 eV、NSW=0、IBRION=-1、LREAL=False。孤立结构使用每侧 10 Å 真空的超胞；只有固定几何单点，不做优化或 AIMD。

`IVDW=12` 对应 D3(BJ)，依据 [VASP 官方 D3 文档](https://vasp.at/wiki/DFT-D3)。标签使用力一致的 free_energy，依据 [VASP smearing 文档](https://vasp.at/wiki/Smearing_technique)。首个 CO2 单点达到了 EDIFF；其 TOTEN、无熵能和零展宽外推能在 OUTCAR 输出精度下相同。但这不替代截断能、晶胞、赝势和作用能参考精度的验证。

MACE-POLAR 的原始训练来源为 OMol25；该数据集使用 omegaB97M-V/def2-TZVPD，见 [MACE-POLAR](https://arxiv.org/abs/2602.19411) 和 [OMol25](https://arxiv.org/abs/2505.08762)。本轮参考方法与之不同。用 PBE-D3 标签微调是适配另一个参考能量面，不能视为同一参考下的追加训练，也不能把预训练模型与 PBE-D3 的差异全部称为模型预测误差。

这一轮只验收实际 DFT 标签能否被收集、训练任务能否完成、新模型能否再加载采样。样本数与训练轮数都不足以形成生产势，不以训练损失下降证明气体物性可靠。正式参考方法应先在目标气体的单体变形、二聚体距离/取向与代表性密度下比较；小分子间弱作用尤其要检查结合能与长程尾部。

## 真实核验结果：匹配参考后误差显著减小，VASP 数值收敛仍待完善

对三个 CO₂ 验证构型新增了 ORCA 6.1.1 的 omegaB97M-V/def2-TZVPD、TightSCF、DEFGRID3 能量/梯度计算。这与 OMol25 的理论级别相同，软件小版本与具体数值细节不声称完全相同。原始 MACE-POLAR S/M/L 相对这些 ORCA 标签的力分量 RMSE 分别为 **0.00775 / 0.00279 / 0.00553 eV/Å**。

在 C–O = 1.178658 Å 的对称 CO₂ 初态上，同一个氧的轴向力为：ORCA **−2.14907 eV/Å**；原始 MACE-POLAR-S **−2.17539 eV/Å**；VASP PBE-D3(BJ), 520 eV 为 **−0.208687 eV/Å**。因此此前相对 PBE 标签约 0.82 eV/Å 的微调验证误差不是原模型对其原始参考的精度。初始结构的 case 名虽含 equilibrium_seed，但它不是本次优化得到的平衡构型。

VASP 固定晶胞、只移动该氧的 z 坐标 ±0.001 Å，中央能量差分给出的力为 **−0.208970 eV/Å**，与解析力相差 **0.000283 eV/Å**。这支持该坐标处能量与力的数值自洽，没有发现足以解释约 1.94 eV/Å 方法差异的符号或单位错误。

将 ENCUT 从 520 提高至 600 eV，轴向力变为 **−0.231546 eV/Å**，变化 **0.02286 eV/Å**。这个变化远小于不同参考方法间的差异，但对高精度力标签已经不可忽略，**所以不能宣布 520 eV 已充分收敛**。真空层与更高截断能仍需系统测试；方法本身的气体相互作用精度也未因此得到证明。

核验最初尝试 EDIFF=1e-9，但在总能量变化和波函数残差很小的同时，band-energy 变化停留在约 6e-9 至 9e-9 eV，无法满足过严阈值。取消这些任务并保留原日志，随后在全新目录用 EDIFF=1e-8 重算，均正常收敛。原训练标签采用 EDIFF=1e-7；未把未收敛输出接收为标签。

结论：PBE 这轮只保留为接口和参考迁移试验，不替换官方 checkpoint。若目标是沿用 MACE-POLAR 的量化化学基准，应使用一致级别的参考数据进行正式微调；不能靠继续训练 PBE 标签来“修复”原模型对 omegaB97M-V 已很小的误差。

核验摘要、解析后的力与作业号见 [force_audit/verification.json](../evidence/round001/force_audit/verification.json)。单次/三个构型的核验不能推广为所有气体环境都已准确。
