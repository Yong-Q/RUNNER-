# HTML 教程设计

使用从 GitHub 获取的 anthropics/skills：doc-coauthoring 与 frontend-design。
读者为准备使用纯气体机器学习势的研究者，重点是从概念理解走到一轮实际作业。

配色：白色 #ffffff、正文深蓝 #15354a、导航蓝 #183f59、完成状态青绿 #087f79、待完成状态棕金 #8b6414、浅底 #edf4f8。字体采用 Noto Sans CJK SC / Microsoft YaHei 的本地字体回退，代码使用等宽字体。页面主体左对齐，最长正文约 42 个汉字，桌面固定目录，手机目录折叠。

布局：
```
左侧阅读目录 | 项目标题 + 当前完成范围
             | 全流程图
             | 贯穿 CO2 示例的概念解释
             | 两个势模型后端的区别
             | 环境、Slurm、逐阶段操作
             | 实测证据、限制、排错、引用
```

视觉重点放在一张可点击的流程图和一个可操作的力分歧例子。其余内容用连续段落、必要表格与代码块组织，不做仪表盘卡片堆叠。所有内容可离线阅读，打印时展开解释块并隐藏操作控件。

复核：技能的逐节确认建议不重复询问用户已明确的中文、教程式与工程可运行目标；以完整草稿后的独立读者检查替代多次中断。
